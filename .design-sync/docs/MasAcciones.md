# MasAcciones

Menú «Más» de la cabecera: agrupa las acciones poco frecuentes o destructivas para que no compitan con la principal. Con `etiqueta` es un botón con texto («Columnas», «Crear relacionado»); con `nombre`, solo el ícono con un nombre propio (el menú de una fila: «Acciones de COM-0142»). Elegir una opción lo cierra.
